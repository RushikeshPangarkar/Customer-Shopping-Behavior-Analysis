# Retail Customer Behavior Analysis

This project explores retail customer purchasing behavior using a sample dataset of customer transactions. It combines SQL analysis, Python-based exploration, and a Power BI dashboard to answer practical business questions about customer spending, product preferences, discounts, subscriptions, and segmentation.

## Project Overview

The goal of this project is to turn raw retail transaction data into clear business insights. The analysis focuses on:

- customer spending patterns
- product popularity and ratings
- discount effectiveness
- subscription behavior
- customer segmentation
- revenue contribution by demographic and behavioral factors

## What's Included

- SQL analysis queries in [Customer Behavior SQL.sql](Customer%20Behavior%20SQL.sql)
- Exploratory analysis notebook in [customer_shopping_behavior.ipynb](customer_shopping_behavior.ipynb)
- Raw source dataset in [customer_shopping_behavior (1).csv](customer_shopping_behavior%20%281%29.csv)
- Power BI dashboard file in [Customer Behavior Dashboard.pbix](Customer%20Behavior%20Dashboard.pbix)

## Dataset Summary

The dataset contains 3,900 customer records and 18 columns, including:

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount (USD)
- Location
- Size
- Color
- Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Payment Method
- Frequency of Purchases

## Business Questions Covered

The SQL script answers the following questions:

1. Total revenue generated by male vs. female customers
2. Customers who used a discount and still spent above average
3. Top 5 products by average review rating
4. Average purchase amount by shipping type
5. Spending comparison between subscribers and non-subscribers
6. Products with the highest discount usage rate
7. Customer segmentation into New, Returning, and Loyal groups
8. Top 3 most purchased products within each category
9. Repeat buyers and their subscription behavior
10. Revenue contribution by age group

## How to Use This Project

### 1. Review the dataset

Open [customer_shopping_behavior (1).csv](customer_shopping_behavior%20%281%29.csv) to understand the available fields and sample transactions.

### 2. Run the SQL analysis

Open [Customer Behavior SQL.sql](Customer%20Behavior%20SQL.sql) in your SQL client and run the queries against a database that contains a table named `customer`.

> If your environment uses a different schema or table name, update the SQL accordingly before running it.

### 3. Explore the notebook

Open [customer_shopping_behavior.ipynb](customer_shopping_behavior.ipynb) in Jupyter Notebook or VS Code to inspect the data interactively.

### 4. Open the dashboard

Open [Customer Behavior Dashboard.pbix](Customer%20Behavior%20Dashboard.pbix) in Power BI Desktop to view the visual dashboard.

## Key Insights

This analysis highlights several useful retail patterns, including:

- Subscribers tend to spend differently than non-subscribers
- Some products stand out with stronger review performance
- Discount usage is closely tied to purchase behavior
- Customer segmentation reveals distinct buying patterns across groups
